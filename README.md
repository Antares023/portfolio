## ✨ Features

- **Dynamic Github-inspired UI**: A clean, dark-mode aesthetic inspired by developer tools.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop views.
- **Interactive Terminal**: Custom typing animation to introduce technical skills.
- **Integrated Guestbook**: Built with [Giscus](https://giscus.app/), allowing visitors to leave comments directly linked to Github Discussions.
- **SEO Optimized**: Pre-configured with meta tags, sitemaps, and `robots.txt` for maximum visibility.
- **Google Analytics Integration**: Track visitor data and interactions effectively.

---

## 🛠️ Tech Stack

- **Frontend Core**: React 19, Vite
- **Styling**: TailwindCSS v4
- **Routing**: React Router DOM
- **Icons & Graphics**: Lucide React
- **SEO & Tracking**: React Helmet Async, Google Analytics
- **Deployment**: Vercel

## 🚀 Quick Start (Local Development)

If you'd like to run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Antares023/portfolio.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` with your browser to see the result.
